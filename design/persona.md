# Persona: Bob

## Background
Bob is a 34-year-old software developer who has been blind since birth. 
He is proficient with screen readers (NVDA on Windows, VoiceOver on Mac) 
and exclusively uses keyboard navigation. Bob recently enrolled in an 
online Python OOP course, but many tutorial videos display code examples 
and diagrams visually without audio descriptions of the on-screen content.

## Goals
- Watch video tutorials independently without relying on sighted help
- Read code examples and text displayed in video frames
- Navigate the video player controls using only the keyboard
- Access extracted text with his screen reader

## Needs
- Full keyboard navigation (Tab, Space, arrow keys)
- Screen reader compatibility (all controls must have labels)
- OCR text extraction from any video frame
- Extracted text displayed in an accessible format (live region)
- Clear visual focus indicators for keyboard navigation

## Frustrations
- Many video players are mouse-dependent and inaccessible
- Tutorial videos often show code on screen without audio narration
- Pausing a video to read text is not possible when you can't see the screen

## Motivations
- Wants to upskill and complete his Python OOP course independently
- Values self-sufficiency and equal access to educational content

## Technology
- Desktop PC with Windows, NVDA screen reader
- Keyboard-only input (no mouse)
- Prefers simple, lightweight web applications

## Experience
- Experienced software developer (8+ years)
- Expert-level screen reader user
- Comfortable with command-line tools and web APIs

## Personality
- Patient and methodical
- Problem-solver mindset
- Values accessibility and inclusive design

## Interests
- Programming, assistive technology, online learning
